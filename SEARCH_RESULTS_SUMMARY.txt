KEY FINDINGS SUMMARY
================================================================================

1. BEAM REPRESENTATION & STRUCTURE
   - Beams created from Figure edges (vertices connected)
   - Each beam has: start point, end point, length, width, thickness
   - TypeScript Beam interface in /src/types/product.ts
   - Original Product.Rib.Beam class in /src/acidome.js lines 5300-5707

2. MEASUREMENTS CALCULATED FOR EACH PIECE
   - Length: Distance between vertices
   - Width: Parallel to radius (mm) - user parameter
   - Thickness: Perpendicular to radius (mm) - user parameter
   - midLength: Center section length
   - maxLength: Extended length including bevels
   - minLength: Minimum length with bevels
   - Volume: midLength x width x thickness x R^3

3. REFERENCE DIMENSIONS & DISPLAY
   - Bevel angles: Inner (bevelInner), left/right (bevelSides)
   - Connector types: Piped, Joint, GoodKarma, Semicone, Cone
   - Material: "Beams XxYmm" (e.g., "Beams 120x40mm")
   - Angle between connected faces
   - Base area for edge beams

4. CANVAS DRAWING SYSTEM (HTML5 Canvas 2D)
   - Plotter base class: Manages 2D context
   - Methods: line(), circle(), text(), textByLine()
   - Plotter.Beam: Beam technical drawings (lines 6162-6298)
   - Plotter.Triangle: Face/panel drawings (lines 6304-6395)
   - Coordinate mapping: Data space -> Canvas pixels

5. TECHNICAL DRAWING OUTPUT
   - Line segments with dashed/solid styles
   - Text labels positioned along lines
   - Vertex circles with index labels
   - Angle annotations at connector joints
   - Bevel specifications with degrees

6. BEAM PROPERTIES EXTRACTION
   - From edges: vertexA, vertexB (3D vectors)
   - From parameters: width, thickness (mm)
   - Calculated: length, volume, bevels, material
   - Grouped by size

7. BEAM INDEXING & LABELING
   - Single letters A-Z for beams 0-25
   - Double letters AA-AZ, BA-BZ for 26+
   - Each drawing has index, measurements, angles, vertices
