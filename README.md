# 🔵 Acidome - Geodesic Dome Calculator

Professional refactoring of the ACIDOME geodesic dome calculator with modern web technologies.

## 🎯 Objectives

This refactorization aims to:

- ✅ Maintain 100% of original functionality
- ✅ Improve code quality and maintainability
- ✅ Implement professional software architecture
- ✅ Add TypeScript for type safety
- ✅ Use modern frameworks (Vue 3, Vite)
- ✅ Support testing and CI/CD
- ✅ Follow industry best practices

## 📦 Tech Stack

### Framework & Build
- **Vue 3**: Modern reactive UI framework
- **Vite**: Lightning-fast build tool and dev server
- **TypeScript**: Type-safe JavaScript
- **SCSS**: Enhanced CSS preprocessing

### State Management & Rendering
- **Pinia**: Official Vue state management
- **Three.js**: 3D graphics and visualization
- **Lodash**: Functional programming utilities

### Development & Quality
- **ESLint**: Code linting
- **Prettier**: Code formatting
- **Vitest**: Unit testing framework
- **Cypress**: Integration testing (optional)

## 🏗️ Project Structure

```
acidome-app/
├── public/
│   └── index.html              # Entry HTML
├── src/
│   ├── types/                  # TypeScript type definitions
│   ├── core/                   # Business logic (Metrics, Figure, Product)
│   ├── ui/                     # Vue components & stores
│   ├── utils/                  # Configuration, i18n, helpers
│   ├── App.vue                 # Root component
│   ├── main.ts                 # Entry point
│   └── style.scss              # Global styles
├── vite.config.ts              # Vite configuration
├── tsconfig.json               # TypeScript configuration
└── package.json                # Dependencies
```

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development
npm run dev

# Build for production
npm run build

# Run tests
npm run test

# Lint & format
npm run lint
npm run format
```
